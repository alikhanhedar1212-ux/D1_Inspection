# 当前下楼任务：第一扇门前等待

2026-10-23 用户确认本阶段只在第一扇门前等待开门，不穿门、不下楼。

1. 新语音“下楼”触发导航到 waypoints.yaml 已确认的1号点。
2. 位置范围30厘米、朝向容差15度。共享二维目标检查器也使用该范围。
3. Nav2成功后调用停车服务锁零；核对新鲜定位仍在等待范围内、速度桥零指令，以及实测机身连续0.6秒低于0.03米/秒和0.05弧度/秒。
4. 停稳检查通过后播报“请帮我开门”，进入 door_1_wait，持续停车。
5. 等待状态不自动计时通过，不询问通行许可；说“确认”不触发运动，进/出门指令被拒绝。说“停止”可结束任务；旧任务不自动重放。

此模式 first_door_wait_only=true 不依赖三维窗口或交接服务，不播放“三维地图起始位置已确认”。execution_enabled=false 保持。

使用已保存的一号点，不声称已完成门框自动识别或居中。现场到点、停稳和播报效果仍需用户发新口令验证。

旧三维交接实现保留作后续开发，本阶段不会调用。
